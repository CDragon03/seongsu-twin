# 성수 디지털트윈 시뮬레이션

성수동 연무장길 일대를 공공데이터로 세운 디지털트윈 위에서, 실제로 일어날 수 있는 재난·생활 상황을 돌려 보는 웹 시뮬레이션입니다.
화면의 수치는 시각화용 추정치이며, 공식 피해 예측이 아닙니다. 각 시뮬레이션의 가정은 화면 조작판에 적어 두었습니다.

- 열기: `index.html` (로컬 서버 또는 GitHub Pages)
- 둘러보기: 일반 보기 · 360 보기 · 어디서든 G 자유 비행 · V 항공 보기 · Q 그늘 효과
- 계절(봄·여름·가을·겨울)·날씨(맑음·비·눈) 버튼: 해 높이·하늘·가로수 색·눈 쌓임
- 시뮬레이션 8종: 화재·연기 확산 · 지진 · 일조·그림자 · 가스 폭발 · 인파 밀집 · 감염병 확산 · 집중호우 침수 · 대피
- 사람은 충돌시험 더미 모양 모형입니다(Higgsfield · Meshy 6 로 생성, 뼈대·걷기 동작 포함).

## 계산 근거(가정 포함)
| 시뮬레이션 | 근거 | 비고 |
|---|---|---|
| 화재 | 건물 간격·구조·바람으로 옮겨붙는 확률 | 출처 없는 가정식 |
| 지진 | 내진설계 의무 연혁(1988·2005·2017) + EMS-98 취약도·피해 등급 단순화 | 연혁은 법령 원문 대조 전 |
| 일조 | 일반 천문 계산식(태양 고도·방위) + 건물 높이로 가림 판정 | 나무·지형 제외 |
| 가스 폭발 | TNT 환산 + Mills(1987) 과압 식, Clancey(1972) 피해 기준 | 기준값 원문 대조 전 |
| 인파 | Weidmann(1993) 밀도-속도 식, 1m²당 5명 위험 | 실제 유동인구 아님 |
| 감염병 | 일반 호흡기 감염병 가정(3m 접촉, 잠복 2~5일, 감염 5~8일) | 특정 질병 아님 |
| 침수 | 배수 능력을 넘는 비를 낮은 곳부터 채움, 30분 시간 상수로 빠짐 + 서울시 침수흔적도 겹쳐 비교 | 하수관·한강 수위 제외, 실제 흔적과 거의 안 맞음(내수침수) |
| 대피 | 건물에서 20m 이상 떨어진 빈터 자동 탐색 + 인파 계산 | 지정 대피소 아님 |
